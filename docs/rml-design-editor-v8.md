# Kormatal RML UI Converter v8

## Изменения интерфейса

1. **Пустой исходный интерфейс при запуске.** Рабочее пространство не загружает демонстрационный проект автоматически. В списке «Исходный интерфейс» отображаются только созданные или импортированные пользователем файлы.
2. **Русский интерфейс.** Основные элементы редактора, панели файлов, экспорта, диагностики, визуального редактирования, базы знаний и инструкции UE5 переведены на русский. Названия API, CSS-свойств, файлов и узлов Unreal Engine сохранены там, где они нужны для точности инструкций.
3. **Сворачиваемая диагностика.** Правая панель «Диагностика совместимости» сворачивается в узкую боковую полосу и раскрывается повторным нажатием.
4. **Пустой список демонстрационных пресетов.** `PRESET_PROJECTS` теперь пуст; демо-проекты не подставляются по умолчанию.
5. **Сохранение проекта.** Кнопка «Сохранить» записывает имя проекта, файлы и настройки (в том числе имя экрана и режим CSS px → dp) в `localStorage` текущего браузера. Пустой проект сохранить нельзя. Повторное сохранение выбранного проекта обновляет существующую запись.
6. **Выбор сохранённого проекта.** Селектор в прежнем месте демо-пресетов показывает проекты, сохранённые в этом браузере. Выбор восстанавливает файлы и настройки; кнопка «Новый» очищает рабочее пространство.

## Дополнительные исправления

- Восстановлен исходный порядок внешних и встроенных классических JavaScript-скриптов в процессе конвертации и при разделении HTML на файлы.
- Добавлено рекурсивное раскрытие локальных CSS `@import` с сохранением порядка, медиа-условий и диагностикой циклов, отсутствующих и внешних импортов.
- Сохраняется консервативная модель Auto-Fix: неоднозначные исправления не переписывают исходные CSS/JS глобальными заменами.
- Матрица совместимости RCSS проверяется на синхронизацию с каталогом свойств.
