# Исправление импорта Layout Generator — v15

## Причина

`LayoutGeneratorModal` и парсеры SVG/Figma JSON находились в исходниках, но модальное окно не было подключено к `App.tsx`, а в `Header` не было кнопки его открытия. Поэтому импорт через обычную панель «Файлы проекта» сохранял SVG/JSON как обычные файлы и не создавал Layout IR, предпросмотр или RML/RCSS.

## Исправлено

- Подключён `LayoutGeneratorModal` к главному приложению.
- В шапку добавлена кнопка «По макету» и такая же команда для пустого рабочего пространства.
- Импорт одного SVG через общую панель файлов передаёт содержимое генератору и автоматически строит Layout IR.
- Импорт одного JSON открывает генератор даже если структура отличается от ожидаемого Figma JSON. Если Frame/Component не найден, в окне показывается конкретная ошибка схемы вместо ситуации, когда внешне «ничего не произошло».
- При выборе нескольких файлов только SVG/JSON JSON используется как структура Figma, а сопутствующие SVG-файлы сохраняются в проекте.
- Парсер Figma JSON продолжает выбирать крупнейший Frame по умолчанию и показывает диагностику, если нет подходящего дерева слоёв.
- После команды «Создать RML/RCSS в проекте» файлы добавляются в рабочее пространство, активным становится созданный RML, а режим переключается на «Код + предпросмотр».
- Повторная генерация заменяет файлы только в папке того же имени, сохраняя остальные файлы проекта.

## Ограничения

- JSON должен содержать дерево слоёв с `document`/`children`, узлами Frame/Component и `absoluteBoundingBox` или соответствовать поддерживаемому экспорту Figma-плагина. При другом формате окно теперь объясняет причину, но не может автоматически угадать произвольную JSON-схему.
- В многофайловом импорте структура создаётся из JSON; сопутствующие SVG-файлы сохраняются в проекте. Их назначение в качестве отдельных image fills требует явной ссылки/идентификатора ресурса в JSON и может потребовать ручного сопоставления.
- Vite build, браузерная визуальная проверка и Unreal Engine/VaCuus runtime не запускались.
