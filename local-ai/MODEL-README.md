# Локальная модель для генератора макетов VaCuus

Модель распознавания: **Qwen3-VL-2B-Instruct**, GGUF Q4_K_M; vision-проектор Q8_0. Модель нужна только для распознавания структуры PNG-макета. SVG и Figma JSON обрабатываются детерминированно без нейросети.

## Установка

В Windows PowerShell запустите `Install-Local-Model.ps1`. Он скачает модельные веса и официальный `llama.cpp` runtime (закреплённый релиз b11711, прямой HTTPS URL без GitHub REST API). Затем запустите `Start-Local-AI.ps1`. После первичной установки можно отключить интернет: все изображения отправляются только локальному адресу `127.0.0.1:8081`.

Источник: [официальная карточка Qwen GGUF](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct-GGUF), лицензия в карточке — Apache-2.0. SHA-256 сверяйте после загрузки; скрипт установки останавливается при несовпадении.

**Бинарные веса не включены в исходный ZIP**: среда создания архива не имела доступа к загрузке гигабайтных файлов из Hugging Face. Скрипт установит их один раз на целевом компьютере или можно перенести скачанные файлы вручную.

## Перенос на компьютер без интернета

1. На машине с интернетом выполните установку и дождитесь проверки SHA-256.
2. Скопируйте папку `local-ai/models/` и `local-ai/runtime/` на внешний диск или в офлайн-архив вместе с исходниками редактора.
3. На отключённом от интернета компьютере распакуйте эти папки в `local-ai/`; не запускайте установщик. Выполните `Test-Local-AI.ps1`, затем `Start-Local-AI.ps1`.

В этом исходном ZIP сами бинарные веса не вложены: сетевой загрузчик в окружении сборки не смог получить файлы Hugging Face. Для полностью автономной установки нужны файлы из таблицы выше.


**Важно:** при первом скачивании нужен обычный доступ HTTPS к Hugging Face и GitHub Release. Использование модели после установки полностью локальное. Ни Gemini, ни облачный AI API, ни ключ провайдера не используются.
