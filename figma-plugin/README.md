# Kormatal Layout Exporter — Figma plugin

Небольшой локальный plugin экспортирует выделенные Frame/Component в JSON, совместимый с вкладкой **Figma JSON** в VaCuus UI Converter → «Создать интерфейс по макету».

## Установка в Figma Desktop

1. В Figma Desktop откройте **Plugins → Development → New Plugin…** и создайте локальный плагин с UI. Figma создаст уникальный `id` в `manifest.json` — сохраните этот ID, не подставляйте произвольный.
2. Скопируйте `code.js` и `ui.html` из этой папки в папку созданного плагина.
3. В сгенерированном Figma `manifest.json` сохраните выданный `id`, а значения `name`, `main`, `ui`, `editorType`, `documentAccess` и `networkAccess` установите как в шаблоне `manifest.json` из этой папки. Пути должны указывать на скопированные `code.js` и `ui.html`.
4. Сохраните файлы и запустите **Kormatal Layout Exporter** через **Plugins → Development**.
5. Выберите один или несколько целых Frame/Component и нажмите экспорт.
6. Перетащите скачанный `.json` в Layout Generator → **Figma JSON**.

Шаблон в этой папке не содержит `id`, потому что Figma сама выдаёт этот идентификатор. Остальные поля подготовлены для локального плагина, включая обязательный `documentAccess: "dynamic-page"` и запрет сетевых запросов через `networkAccess.allowedDomains: ["none"]`.

## Что экспортируется

Иерархия узлов, абсолютные границы, видимость, поддерживаемые заливки/обводки, радиусы, текстовые параметры (включая line-height/letter-spacing), Auto Layout и метаданные эффектов. Узлы сериализуются с проверкой свойств конкретного типа, поэтому группы и Slice не должны ломать экспорт из-за отсутствующих `fills`/`opacity`.

Векторы, градиенты, image fills и сложные эффекты на отдельных графических слоях растеризуются в PNG 2× и вкладываются прямо в JSON. Для каждого выбранного Frame также добавляется PNG-эталон 1×. Импортёр автоматически использует его для pixel-reference `main.rml`, а встроенные PNG-слои подключает в редактируемом `main-editable.rml` как отдельные ресурсы `Assets/`. Это сохраняет внешний вид, но такие графические слои не становятся редактируемыми векторами. `BACKGROUND_BLUR` передаётся как VaCuus `backdrop-filter: blur(...)`; остальные эффекты, которые не удалось включить в отдельный графический слой, остаются в диагностике.

Размер JSON ограничен 10 МБ, чтобы файл гарантированно проходил лимит импорта Layout Generator (12 МБ). Для больших макетов экспортируйте нужный Frame отдельно или уменьшите число растеризуемых слоёв.

Плагин работает локально в редакторе Figma. `documentAccess: "dynamic-page"` совместим с современной моделью доступа к документу, а `networkAccess.allowedDomains: ["none"]` запрещает сетевые запросы. Плагин не отправляет данные внешним API.
