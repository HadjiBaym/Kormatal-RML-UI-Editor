Kormatal Layout Exporter

Экспортирует выбранные Frame/Component в переносимый JSON для Layout Generator: дерево и координаты, текстовые стили, PNG-эталон экрана и PNG-ресурсы для векторов, изображений и сложных заливок.

Перед экспортом

Выберите один или несколько целых Frame на холсте. PNG-слои и эталон включаются в JSON автоматически; лимит экспортного файла — 10 МБ.
