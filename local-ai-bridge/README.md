# Локальный мост для VaCuus UI Converter

Мост нужен, если редактор открыт в удалённом web-preview (например, AI Studio), а LM Studio/Qwen запущен в вашей локальной сети. Веб-сервер удалённого preview не имеет доступа к `192.168.x.x`; мост переносит запросы через процесс Node.js на вашем компьютере.

## Требования

- Windows 10/11 и Node.js 22 или новее.
- LM Studio на вашем компьютере или на другом компьютере в той же доверенной LAN.
- Для LM Studio: Developer → Server → Start Server. Если модель на другом компьютере, включить **Serve on Local Network**. Включайте сетевое прослушивание только в доверенной сети.

## Запуск

1. Запустите `Start-Local-Bridge.bat`.
2. Скопируйте случайный токен, напечатанный в консоли.
3. В VaCuus UI Converter → генератор макета → **Откуда проверять подключение** выберите **Локальный мост**.
4. Оставьте адрес моста `http://127.0.0.1:17891`, вставьте токен.
5. Для LM Studio задайте модельный URL, например `http://192.168.1.22:1234/v1`, затем нажмите «Проверить подключение». Можно нажать проверку до ввода model ID, чтобы обнаружить список моделей; затем выберите точный ID в списке.
6. Не закрывайте окно моста во время анализа.

## Безопасность

- Мост слушает только `127.0.0.1`, не принимает входящие соединения из LAN.
- Каждая проверка/передача изображения требует случайный токен из 192 бит, напечатанный при запуске.
- Целевой endpoint ограничен `localhost` или частными IPv4 диапазонами RFC1918. Публичные IP и HTTPS блокируются.
- Мост не использует внешние API; изображение направляется только на модельный URL, который вы указали.
- Если браузер покажет запрос разрешения на доступ сайта к локальной сети, разрешите его для страницы конвертера. Если браузер или политика организации блокирует обращение к localhost из удалённой страницы, запустите сам конвертер локально — это более надёжный режим.
